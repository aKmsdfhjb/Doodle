# Doodle Recognition — Project Wiki

A five-class sketch recognition project trained on Google Quick, Draw! categories: Apple, Cookie, Dog, Eye and Face. The browser canvas is separate from the Flask/TensorFlow inference service.

## Quick start

```bash
cd "doodle-quickdraw/backend"
pip install -r requirements.txt
python app.py
```
